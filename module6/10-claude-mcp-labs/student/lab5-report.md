# Lab 5 — รายงาน: จาก ids-report-v1 เป็น dashboard และ PDF (G4)

**หัวข้อ** M6.3 (pandas → Jinja2 → PDF, 8.1–8.3), M6.4 (dashboard 9.4) · **เวลา** 45 นาที

## โจทย์

69% ของ SOC ยังทำรายงานด้วยมือ (SANS 2025) ผู้เรียนให้ Claude เปลี่ยน JSON report ที่ผ่าน contract แล้วเป็น (1) dashboard แบบ Artifact (2) PDF 1 หน้าสำหรับผู้บริหาร โดย **ตัวเลขทุกตัวต้องมาจาก report ไม่ใช่จาก Claude**

## สิ่งที่ต้องค้นให้ได้

คำถามข้างล่างคือสิ่งที่ analyst จะถามกันเมื่อเจอเรื่องนี้หน้า SIEM ผู้เรียนต้องตอบทุกข้อเป็นลายลักษณ์อักษร คอลัมน์ขวาบอกว่าคำตอบต้องมาจากผลของ tool ใด (ระบุชื่อ tool และฟิลด์ที่อ่านค่ามา) ไม่รับคำตอบที่ Claude สรุปให้โดยไม่มี tool รองรับ ข้อที่เป็นการตัดสินใจไม่มีคำตอบตายตัวแต่ต้องอ้างตัวเลขที่ค้นได้ บันทึกคำตอบในส่วน "บันทึกคำตอบ" ด้านล่าง

| --- | --- | --- |
| 1 | ผู้บริหารถามว่า "ช่วงนี้เกิดอะไรขึ้น" ตอบด้วยตัวเลขอะไร 3 ตัว | report JSON: `total_records`, `parsed`, `failed` ตรงกับ lab 2 |

## prompt ที่ผู้เรียนพิมพ์

```
อ่าน report ที่ /m6-10/<ชื่อ>/lab2-ids/report แล้วทำ dashboard: KPI (total, parsed, failed), bar chart ตาม signature,
ตาราง top destination แล้วทำ PDF 1 หน้าสรุปสำหรับผู้บริหาร ภาษาไทย
ระบุ sha256 ของ report และ job_id ไว้ท้ายหน้า
```

## ลำดับ tool ที่ควรเห็น

1. `hdfs_list` → `hdfs_read_text` part-*.txt → `hdfs_sha256`
2. `log_skill_validate_report` (ซ้ำ เพื่อให้แน่ใจว่าไฟล์ที่อ่านคือฉบับที่ผ่าน)
3. Artifact (HTML dashboard) — ตัวเลขจาก JSON โดยตรง
4. skill pdf (Bash + reportlab/weasyprint) → ไฟล์ PDF ในโฟลเดอร์งานของผู้เรียน
