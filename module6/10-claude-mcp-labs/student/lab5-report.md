**หัวข้อ** M6.3 (pandas → Jinja2 → PDF, 8.1–8.3), M6.4 (dashboard 9.4) · **เวลา** 45 นาที

## สถานการณ์

เช้าแล้ว ผู้บริหารถามว่าเมื่อคืนเกิดอะไรขึ้น ขอหนึ่งหน้า น้องมีตัวเลขจาก lab 2 ที่ตรวจแล้ว และรู้จาก lab 3 ว่าอะไรยืนยันได้และอะไรยังไม่ได้ คำถามที่พา lab นี้คือ จะเล่าให้คนที่ไม่รู้จัก Suricata เข้าใจได้อย่างไรโดยไม่พูดเกินหลักฐาน จะใช้คำว่า "rule ตรง" หรือ "ถูกโจมตี" และจะบอกตรง ๆ อย่างไรว่าอะไรยังไม่รู้

## คำถามที่ถาม Claude ต่อ

เมื่อ prompt แรกทำงานเสร็จ ให้พิมพ์คำถามข้างล่างถาม Claude ต่อทีละข้อ เหมือนถามเพื่อนร่วมทีมหน้า SIEM งานของผู้เรียนไม่ใช่ไปค้นเอง แต่คือตรวจคำตอบ Claude ต้องอ้างได้ว่าคำตอบมาจาก tool ใดและฟิลด์ใด (คอลัมน์ "คำตอบต้องอ้างอะไร") ถ้าตอบโดยไม่เรียก tool หรือไม่บอกที่มา ให้สั่งว่า "อ่านจาก tool แล้วบอกฟิลด์ที่ใช้" และสุ่มเทียบตัวเลขอย่างน้อย 1 ค่าต่อ lab กับ output ดิบด้วยตาตัวเอง ข้อที่ประเภทเป็น **ตัดสิน** Claude เสนอได้ แต่คนเป็นผู้ตัดสินและเขียนเหตุผลเอง บันทึกในส่วน "บันทึกคำตอบ" ด้านล่าง

## ลำดับ tool ที่ควรเห็น

1. `hdfs_list` → `hdfs_read_text` part-*.txt → `hdfs_sha256`
2. `log_skill_validate_report` (ซ้ำ เพื่อให้แน่ใจว่าไฟล์ที่อ่านคือฉบับที่ผ่าน)
3. Artifact (HTML dashboard) — ตัวเลขจาก JSON โดยตรง
4. skill pdf (Bash + reportlab/weasyprint ถ้ามี; เครื่องผู้สอน 2026-11-03 ไม่มีทั้งสอง ใช้ matplotlib `PdfPages` แทนได้ ต้องใช้ฟอนต์ที่มีทั้งไทยและละติน เช่น `/System/Library/Fonts/Supplemental/Ayuthaya.ttf` ส่วน ThonburiUI.ttc ไม่มี glyph ละติน) → ไฟล์ PDF ในโฟลเดอร์งานของผู้เรียน
